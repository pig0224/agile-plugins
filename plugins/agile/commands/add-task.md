# /agile:add-task — 补充遗漏任务

先阅读 skill `sdd-tdd-method`，然后按以下步骤执行。

## 输入

- 解析 `$ARGUMENTS`：第一段为需求编号，其余为遗漏任务的描述（可为多条，分行或分号分隔）。

## 执行步骤（只追加原则）

1. 根据任务归属确定角色文件：后端任务 → `implementation-be.md`，前端任务 → `implementation-fe.md`；读对应文件的「任务清单」章节。
2. 根据 design.md 与 gen-test.md 把新任务描述规范化为任务条目（动词开头、可验证完成）。
3. **追加**到该角色文件清单末尾，编号顺延（已有任务条目、已勾选状态一律不动）；同时在 `implementation.md` 任务分配表**追加一行**（主文件只追加行，不改既有行）。
4. 若新任务与既有任务明显重复，不追加，改为汇报重复项。
5. 涉及新模块/新项目时，提醒检查 `projects/` 下是否已有该项目目录（没有则给出 `agile init project <name> --template <模板>` 命令）。

## 输出

汇报：追加的任务条目（含编号）、是否发现重复、清单当前总数。
